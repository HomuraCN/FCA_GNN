# FCA-GNN Command Line Experiments

This folder contains script entry points for data generated by:

```bash
/Users/didi/code/mix/fca/FCA/scripts/build_categorical_experiment_input.sh \
  --dataset car \
  --input-dir /abs/path/to/raw_csv_folder \
  --output-dir /abs/path/to/generated_inputs
```

The Java side expects:

- `/abs/path/to/raw_csv_folder/{dataset}.csv`
- `/abs/path/to/raw_csv_folder/{dataset}_col.csv`

The Python side reads `/abs/path/to/generated_inputs/{dataset}_input` and writes all runs/results to
`/abs/path/to/experiment_outputs/{dataset}_output`.

Run all six core results:

```bash
conda run -n normal python /Users/didi/code/mix/fca/FCA_GNN/scripts/run_all_experiments.py \
  --dataset car \
  --input-dir /abs/path/to/generated_inputs/car_input \
  --output-dir /abs/path/to/experiment_outputs \
  --epochs 150 \
  --threshold-pos 128 \
  --threshold-neg 5000 \
  --topk 8 32
```

For datasets where adjacency matrices are too expensive, such as nursery-style larger categorical datasets, skip adjacency matrix generation on the Java side:

```bash
/Users/didi/code/mix/fca/FCA/scripts/build_categorical_experiment_input.sh \
  --dataset nursery \
  --input-dir /abs/path/to/raw_csv_folder \
  --output-dir /abs/path/to/generated_inputs \
  --skip-adjacency true
```

Then run only the bipartite experiments:

```bash
conda run -n normal python /Users/didi/code/mix/fca/FCA_GNN/scripts/run_all_experiments.py \
  --dataset nursery \
  --input-dir /abs/path/to/generated_inputs/nursery_input \
  --output-dir /abs/path/to/experiment_outputs \
  --epochs 150 \
  --topk 8 32 \
  --skip-adjacency true
```
